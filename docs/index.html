1. Introduction & Philosophy

The LLM Evaluation Framework is a production-grade Python suite and pedagogical lab designed to test, benchmark, and evaluate non-deterministic GenAI applications, Retrieval-Augmented Generation (RAG) pipelines, and autonomous multi-turn agents.

Core Principle: In traditional software testing, pass/fail is deterministic and binary. In GenAI evaluation, we test for semantic adherence, hallucination probability, safety refusals, and trajectory efficiency.

2. Quickstart & Installation

# 1. Clone the repository git clone https://github.com/aasthadhoundiyal/llm-evaluation-framework.git cd llm-evaluation-framework # 2. Run all evaluation phases out-of-the-box (Zero setup, offline mock mode) python -m eval_framework.cli run-all --provider mock # 3. Launch the interactive Observatory Dashboard python -m eval_framework.cli serve --port 8080

3. The 6-Phase Evaluation Curriculum

Phase 0: Foundations & NLP Baselines

Covers classical NLP token Exact Match (EM) and F1 scoring (SQuAD baseline) and examines why lexical equality fails on generative models. Introduces keyword containment and regex validation.

Phase 1: Multi-Model Benchmarking

Runs standardized prompts across multiple local (Ollama) and frontier cloud models, tracking latency, tokens, and pass rate matrices.

Phase 2: Core Evaluation Techniques

  • LLM-as-a-Judge: Structured rubric evaluation (Accuracy, Tone, Policy, Reasoning).
  • Semantic Similarity: Cosine similarity, ROUGE-L, and BLEU-4 metrics.
  • Groundedness: Claim extraction and hallucination auditing.
  • Adversarial Injection: Prompt injection defense, system prompt leak resistance.

Phase 3: RAG Triad Pipeline Evaluation

Calculates the 3 pillars of RAG: Context Relevance, Groundedness (Faithfulness), and Answer Relevance, plus temperature sensitivity sweeps.

Phase 4: Industry Standards (Ragas & DeepEval)

Provides zero-friction adapters showing how native evaluators map to Ragas and DeepEval standard metrics.

Phase 5: Autonomous Agents & Tracing

Simulates multi-tool agents, evaluates tool precision/recall, detects infinite reasoning loops, and exports OpenTelemetry/Langfuse traces.

Phase 6: AI Safety & Adversarial Defense

Detects sensitive PII leakage (SSN, Luhn credit cards, API secrets), evaluates prompt injection and DAN jailbreak resistance, and audits security compliance.

4. Supported Model Providers

  • mock: Built-in deterministic simulation for lightning-fast testing without API keys or local GPUs.
  • groq: Ultra-low latency LPU inference (e.g. llama-3.1-8b-instant).
  • ollama: Local open-source models (e.g. llama3.1:8b, mistral:7b, deepseek-r1:7b).
  • openai: GPT-4o, GPT-4o-mini, etc.
  • gemini: Google Gemini 1.5 Pro and Gemini 1.5 Flash.
  • anthropic: Claude 3.5 Sonnet, Claude 3.5 Haiku.
